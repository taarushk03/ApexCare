# ApexCare – Smart Digital Healthcare Platform

A full-stack healthcare platform developed using React, Next.js, NestJS, PostgreSQL, and FastAPI. The project provides a modern digital healthcare solution with patient management, appointment scheduling, and AI-powered symptom analysis.

## Features

- User Authentication
- Patient Management
- Appointment Booking
- AI-powered Symptom Analysis
- Responsive User Interface
- REST API Architecture

## Tech Stack

**Frontend**
- React
- Next.js
- TypeScript
- Tailwind CSS

**Backend**
- NestJS
- PostgreSQL
- TypeORM

**AI Service**
- FastAPI
- Python
